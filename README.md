# Jameel's Birthday Website

A responsive birthday quiz experience built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and screens
- `style.css` — responsive design, colors, layout, and animations
- `script.js` — ten knowledge questions, five heart questions, scoring, and copyable results

## Run locally
Open `index.html` in Chrome. No installation or build step is required.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. Wait for the deployment to finish. The Pages panel will show the published website link.

## Notes
- This is a static website; no account or backend is required.
- Quiz responses stay in the visitor's browser. The **Copy my answers** button lets the visitor copy a summary to share manually.
- Do not add passwords, private keys, or other secrets to this public repository.
